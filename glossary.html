🔤 Термины и определения

API интеграция
Набор правил, по которым программы обмениваются данными. «Посредник» между приложениями.
Пример: AI Tunnel даёт API для подключения VS Code к моделям ИИ.
API-ключ безопасность
Уникальный код, идентифицирующий пользователя при обращении к API. Нужно хранить в секрете.
Пример: sk-xxxxxx — ключ, который получают в AI Tunnel для настройки Cline.
CI/CD автоматизация
Непрерывная интеграция и доставка — практика автоматической сборки, тестирования и развёртывания кода.
Пример: при каждом обновлении сайта автоматически запускаются тесты.
CSV формат
Формат табличных данных, где значения разделены запятыми или точками с запятой.
Пример: таблицы из Excel можно сохранить в CSV для загрузки в pandas.
Git контроль версий
Система отслеживания изменений в файлах. Позволяет возвращать старые версии и работать в команде.
Пример: Git хранит историю курсовой – всегда можно вернуться к черновику.
GitHub сервис
Облачная платформа для хранения проектов с использованием Git. Аналог «облака для кода».
Пример: студенты выкладывают курсовые на GitHub и делятся ссылкой с преподавателем.
HTML веб
Язык разметки для создания веб-страниц. Определяет структуру документа.
Пример: заголовки, абзацы, картинки описываются с помощью HTML.
IDE программы
Среда разработки, объединяющая редактор кода, терминал, отладчик и другие инструменты.
Пример: VS Code, PyCharm, IntelliJ IDEA – всё это IDE.
JSON формат
Текстовый формат для хранения и обмена структурированными данными. Часто используется в API.
Пример: настройки расширений VS Code хранятся в JSON-файлах.
Jupyter Notebook инструмент
Интерактивная среда для анализа данных, где можно писать код и сразу видеть результат.
Пример: в VS Code через расширение Jupyter можно запускать ячейки с Python прямо в редакторе.
Markdown формат
Лёгкий язык разметки для форматирования текста (заголовки, списки, таблицы) простыми символами.
Пример: # Заголовок, *курсив*, **жирный**, — список.
MCP (Model Context Protocol) протокол
Универсальный протокол, позволяющий ИИ-агентам подключаться к внешним системам (базам данных, API).
Пример: через MCP агент может сам найти статьи в университетской библиотеке.
Open Source лицензия
Программы с открытым исходным кодом — их можно бесплатно использовать, изучать и изменять.
Пример: VS Code имеет открытый исходный код.
PDF (Portable Document Format) формат
Формат для представления документов, не зависящий от устройства. Удобен для чтения, но труден для редактирования.
Пример: учебные статьи и методички часто раздают в PDF.
Pull request GitHub
Запрос на внесение изменений в чужой проект. Позволяет предлагать правки.
Пример: если нашли ошибку в методичке, можно сделать pull request.
Python язык
Популярный язык программирования. Используется для анализа данных, ИИ, веб-разработки.
Пример: многие расширения VS Code написаны на Python.
Skill (навык) агент
Многоразовая инструкция для агента, которую он загружает по требованию.
Пример: навык «Академический рецензент» проверит курсовую на соответствие ГОСТ.
Subagent (подагент) агент
Специализированный агент, который выполняет часть большой задачи.
Пример: один подагент ищет источники, второй пишет текст, третий оформляет библиографию.
Автодополнение VS Code
Функция, которая предлагает варианты продолжения слов, кода или команд по мере ввода.
Пример: GitHub Copilot подсказывает код на основе комментариев.
Автоматизация процесс
Выполнение задач программой без участия человека или с минимальным вмешательством.
Пример: макросы в Word автоматически оформляют таблицы.
Академический стиль стиль
Официальный, строгий стиль письма без разговорных слов, местоимений «я/мы». Используется в науке и учёбе.
Пример: вместо «я считаю» пишут «можно предположить».
Аннотация научный текст
Краткая характеристика работы, раскрывающая тему, цель, методы и основные результаты.
Пример: аннотация к курсовой работе обычно занимает 100–200 слов.
Библиотека (library) программирование
Набор готовых функций и классов, которые можно использовать в своей программе, чтобы не писать всё с нуля.
Пример: pandas в Python — библиотека для анализа данных.
Бэкенд программирование
Серверная часть приложения, которая обрабатывает данные, работает с базами данных и выполняет основную логику.
Пример: API AI Tunnel — это бэкенд.
Версия (version) ПО
Номер выпуска программы. Обычно состоит из цифр (1.0, 2.1.3).
Пример: VS Code обновляется каждые несколько недель.
ИИ-агент AI
Искусственный интеллект, который не только отвечает, но и выполняет действия (создаёт и редактирует файлы).
Пример: Cline – агент, который сам может написать код или создать файлы в проекте.
Клиент-серверная архитектура программирование
Модель, где клиент (например, VS Code) отправляет запрос, а сервер (AI Tunnel) обрабатывает и возвращает ответ.
Пример: вы отправляете промт → Cline → AI Tunnel → модель → возвращает ответ.
Код (исходный код) программирование
Текст программы на языке программирования (Python, HTML и др.).
Пример: весь код вашего сайта написан на HTML, CSS и JavaScript.
Консоль инструмент
То же, что терминал. Окно для текстового ввода команд.
Пример: открыть консоль VS Code — CTRL+`.
Контекстное окно ИИ
Максимальный объём текста (в токенах), который модель может обработать за один запрос.
Пример: у некоторых моделей контекст 128K токенов – можно загрузить целую книгу.
Кросс-платформенность ПО
Возможность программы работать на разных операционных системах (Windows, macOS, Linux).
Пример: VS Code работает и на Windows, и на Mac.
Кэш браузер/ПО
Временное хранилище данных для ускорения работы. Если сайт отображается неправильно – нужно очистить кэш.
Пример: CTRL+F5 – обновление страницы с очисткой кэша.
Макрос автоматизация
Записанная последовательность действий, выполняемая одной командой. Ускоряет рутинные операции.
Пример: макрос в Word оформляет все таблицы за секунду.
Нейросеть AI
Программа, обученная на больших данных распознавать и генерировать текст, изображения и т.д.
Пример: ChatGPT, Qwen, Claude – нейросети для работы с текстом.
Отладчик (debugger) инструмент
Инструмент для поиска и исправления ошибок в программе.
Пример: в VS Code можно поставить точку остановки и смотреть пошаговое выполнение кода.
Промт запрос
Инструкция, которую пользователь отправляет нейросети, чтобы получить нужный результат.
Пример: «Напиши аннотацию к курсовой» – это промт.
Расширение (extension) VS Code
Дополнительный модуль, добавляющий новые функции в VS Code (подсветку, проверку орфографии, ИИ).
Пример: Russian Language Pack – расширение для русского интерфейса.
Репликация IT
Копирование данных или кода из одного места в другое.
Пример: скопировали файл из папки проекта на GitHub — это репликация.
Репозиторий Git/GitHub
Папка, за которой следит Git. Хранит файлы проекта и всю историю изменений.
Пример: репозиторий курсовой – место, где Git отслеживает правки.
Репозиторий публичный/приватный GitHub
Публичный видят все, приватный — только владелец и те, с кем он поделился.
Пример: курсовую лучше хранить в приватном репозитории.
Синтаксис язык
Правила написания кода или разметки. Если нарушить — программа не поймёт.
Пример: в Markdown # — заголовок, а не просто решётка.
Терминал инструмент
Окно для ввода текстовых команд. В VS Code находится внизу (CTRL+`).
Пример: команда `python --version` показывает версию Python.
Токен ИИ
Минимальная единица текста для нейросети. Может быть словом, частью слова или знаком.
Пример: «Привет, мир!» — это 4 токена (Привет + , + мир + !).
Точка остановки (breakpoint) отладка
Место в коде, где выполнение программы прерывается для анализа.
Пример: клик слева от номера строки — ставится красная точка остановки.
Файловая система компьютер
Способ организации папок и файлов на компьютере.
Пример: Проводник в Windows – это графическое представление файловой системы.
Фреймворк программирование
Более крупный набор инструментов, который диктует структуру проекта (каркас для разработки).
Пример: Jupyter, React, Django — фреймворки.
Фронтенд программирование
Клиентская часть, которую видит пользователь (интерфейс).
Пример: окно чата с нейросетью в VS Code — это фронтенд.
📌 Как пользоваться глоссарием?
Встретили незнакомое слово? Нажмите CTRL+F и найдите его в этом списке. Если термина нет — сообщите автору, глоссарий будет дополняться.
