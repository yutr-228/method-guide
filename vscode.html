Работа через Visual Studio Code

До этого рассматривалась работа в Word и веб-сервисах, однако для серьёзной учебной деятельности требуется единая среда, объединяющая текстовый редактор, файловый менеджер, работу с кодом и нейросети. Такой средой является Visual Studio Code (VS Code).

Работа через Visual Studio Code

Visual Studio Code является удобным и современным инструментом для учебной и профессиональной работы с файлами, текстами и проектами.

Программа распространяется бесплатно, быстро запускается и стабильно работает даже на не самых мощных компьютерах. В отличие от обычных текстовых редакторов, VS Code позволяет удобно работать сразу с большим количеством файлов и папок, быстро находить нужную информацию по всему проекту и использовать встроенные инструменты для структурирования материалов.

В отличие от онлайн-сервисов, VS Code способен работать офлайн и не требует постоянной передачи учебных материалов в облако.

Главным преимуществом является поддержка расширений, таких как Qwen, GitHub Copilot, Office Viewer, Jupyter и других. Благодаря этому VS Code превращается в единую рабочую среду, где нейросети могут не только отвечать на вопросы, но и взаимодействовать с вашей файловой системой: создавать, редактировать и анализировать файлы.

Вывод: VS Code особенно полезен для написания больших учебных работ, анализа материалов, подготовки презентаций, таблиц и систематизации файлов в одном месте.

Установка Visual Studio Code

Шаг 1

Переход на официальный сайт

Откройте любой браузер (например, Chrome, Edge или Firefox), введите запрос «vs code» и перейдите на официальный сайт Visual Studio Code.

Либо воспользуйтесь официальной ссылкой:
https://code.visualstudio.com/

Шаг 2

Скачивание установочного файла

На главной странице нажмите кнопку Download. Сайт автоматически предложит версию под вашу операционную систему (Windows, macOS или Linux).

После нажатия начнётся загрузка установочного файла.

Шаг 3

Запуск установщика

После завершения загрузки откройте скачанный файл или перейдите в папку Загрузки (Downloads) и запустите установку вручную.

Шаг 4

Принятие лицензионного соглашения

В открывшемся окне установщика:

– выберите пункт I accept the agreement;
– нажимайте Next, пока не появится кнопка установки.

Шаг 5

Выбор папки установки

Установщик предложит папку для установки программы. Рекомендуется оставить путь по умолчанию и нажать Next.

Шаг 6

Выбор дополнительных параметров

На этом этапе рекомендуется включить полезные опции:

– add to PATH – позволяет запускать VS Code из командной строки;
– create a desktop icon – создаёт значок на рабочем столе;
– add "Open with Code" – добавляет пункт в контекстное меню.

Рекомендуется отметить все эти параметры, затем нажать Next.

Шаг 7

Установка программы

Нажмите кнопку Install и дождитесь завершения процесса установки.

Шаг 8

Завершение установки и запуск

После окончания установки нажмите Finish. Если установлена соответствующая галочка, программа запустится автоматически.

Шаг 9

Первая проверка

После запуска убедитесь, что программа открылась корректно. При необходимости можно установить расширения через вкладку Extensions.

Привязка VS Code к GitHub

Git - это система контроля версий, которая отслеживает изменения в файлах. Она позволяет хранить историю проекта и при необходимости возвращаться к более ранним версиям.

GitHub - это онлайн-сервис для хранения Git-репозиториев. Он позволяет сохранять проекты в облаке, делиться ими и организовывать совместную работу.

Важно понимать разницу: Git - это технология, а GitHub - это веб-сервис, использующий эту технологию.

Для учебной деятельности это особенно полезно, так как позволяет:

– надёжно хранить историю учебных проектов;
– обмениваться файлами с одногруппниками или преподавателем;
– получать практический навык, востребованный в IT-среде.

Ниже рассматривается порядок регистрации на GitHub и привязки аккаунта к VS Code.

Шаг 1

Откройте браузер и перейдите на официальный сайт:
https://github.com/

Шаг 2

Нажмите кнопку Sign up в правом верхнем углу.

Шаг 3

Введите адрес электронной почты, придумайте пароль и имя пользователя (username).

Шаг 5

После завершения установки рекомендуется перезапустить VS Code.

Создание папки для работы с файлами проекта

Для удобной организации файлов рекомендуется создать отдельную папку проекта перед началом работы в Visual Studio Code.

Шаг 1

Откройте проводник операционной системы (Проводник в Windows или Finder в macOS).

Шаг 2

Перейдите в директорию, где планируется хранение проекта (например, «Документы» или «Рабочий стол»).

Шаг 3

Нажмите правой кнопкой мыши в пустой области. Выберите пункт «Создать» → «Папку».

Шаг 4

Введите название папки. Рекомендуется использовать понятное имя, отражающее содержание проекта (например, Отчёт_по_практике, Анализ_данных, Проект_1).

Шаг 5

Запустите Visual Studio Code. В главном меню выберите: File → Open Folder (Файл → Открыть папку). В открывшемся окне найдите созданную папку.

Шаг 6

Выделите папку и нажмите кнопку «Выбрать папку». После выполнения действий папка отобразится в левой части окна (Explorer). В неё можно добавлять файлы и создавать структуру проекта.

Рекомендации:
– храните все файлы проекта в одной папке;
– создавайте подпапки (например: Документы, Данные, Презентации);
– используйте понятные и единообразные названия файлов.

Работа с файлами в Visual Studio Code

После создания папки проекта пользователь может приступить к работе с различными учебными файлами. Visual Studio Code позволяет удобно организовать материалы, открывать документы и быстро переходить между ними.

Открытие файлов

Для открытия файла необходимо:

  • открыть ранее созданную папку проекта через меню: File → Open Folder;
  • в левой части окна (панель Explorer) выбрать нужный файл;
  • щёлкнуть по нему левой кнопкой мыши.

В Visual Studio Code можно работать с различными типами файлов, например:

  • текстовые документы;
  • таблицы;
  • презентации;
  • PDF-файлы;
  • заметки и черновики.

Организация учебных материалов

Для удобства рекомендуется распределять файлы по тематическим папкам, например:

  • документы – отчёты, рефераты, текстовые материалы;
  • презентации – материалы для выступлений;
  • данные – таблицы, результаты опросов, числовые данные;
  • изображения – схемы, рисунки, иллюстрации;
  • черновики – рабочие записи и промежуточные версии.

Такая структура позволяет быстрее находить нужные материалы и хранить их в одном месте.

Работа с несколькими файлами

При открытии нескольких файлов они отображаются во вкладках в верхней части окна программы. Пользователь может быстро переключаться между ними, не закрывая текущую работу. По умолчанию в Visual Studio Code файл может открываться в режиме предварительного просмотра. В этом режиме при открытии следующего файла предыдущий автоматически заменяется, и отдельная вкладка не создаётся.

Чтобы открыть несколько файлов одновременно, необходимо:

  1. В левой панели Explorer выбрать нужный файл.
  2. Чтобы файл открылся как отдельная вкладка, необходимо: дважды щёлкнуть по файлу левой кнопкой мыши или открыть файл и затем нажать на него повторно.
  3. После этого вкладка файла закрепится в верхней части окна.
  4. Аналогичным образом можно открыть и остальные файлы.

Поиск по файлам

Для быстрого поиска информации можно использовать встроенную функцию поиска. Для этого необходимо:

  1. Нажать сочетание клавиш Ctrl + F.
  2. Ввести нужное слово или фразу.
  3. Просмотреть найденные совпадения в документе.

Настройка AI Tunnel и интеграция с VS Code

В стандартной конфигурации Visual Studio Code возможности работы с нейросетями ограничены встроенными или официально поддерживаемыми решениями (например, GitHub Copilot). Однако в ряде случаев пользователю требуется более гибкий доступ к различным моделям искусственного интеллекта, таким как ChatGPT, Claude, Qwen, Kimi и другим.

Сервис AI Tunnel (https://aitunnel.ru) предоставляет такую возможность, выступая в роли единого API-шлюза для подключения к различным языковым моделям без необходимости использования VPN.

Это особенно актуально в условиях ограниченного доступа к зарубежным сервисам.

Важно учитывать следующие особенности:
  • сам сервис AI Tunnel является бесплатным;
  • однако использование моделей платное – списание средств происходит за обработку запросов;
  • стоимость зависит от выбранной модели и объёма передаваемых данных (входных и выходных токенов).

Таким образом, AI Tunnel целесообразно использовать в случаях:

  • при необходимости профессиональной работы с ИИ;
  • при интеграции ИИ в собственные проекты;
  • при выполнении сложных задач (анализ, генерация, обработка данных);
  • при разработке программных продуктов с использованием ИИ.

Интеграция с Visual Studio Code осуществляется через расширение Cline, которое позволяет напрямую взаимодействовать с моделями внутри редактора.

Регистрация в AI Tunnel является обязательным этапом, поскольку доступ к нейросетевым моделям осуществляется через API, требующий авторизации. В рамках данного сервиса создаётся уникальная учётная запись пользователя, к которой привязываются: API-ключи, баланс средств и история запросов.

Основные элементы интерфейса Cline

Верхняя панель

Содержит кнопки: создание нового чата, история диалогов, настройки подключения моделей, управление аккаунтом, MCP Servers. Через эту панель выполняется настройка API и переключение между моделями. MCP (Model Context Protocol) Servers – это специальные серверы или п модули, которые позволяют ИИ-ассистенту получать дополнительный доступ к внешним инструментам, данным и функциям.

Центральная панель

Отображаются сообщения пользователя и ответы модели. В верхней части ответа иногда указывается стоимость обработки запроса – это позволяет контролировать расходы.

Нижняя панель ввода

Текстовое поле для запросов. Справа отображается текущая используемая модель (например, moonshot:kimi-k2.5). Нажав на название, можно переключить модель.

Режимы Plan и Act

Plan – режим анализа и планирования (объясняет, не изменяет файлы). Act – режим активного выполнения действий (создаёт, редактирует файлы, изменяет структуру проекта). Перед действиями Cline запрашивает подтверждение.

Символы @ и / и drag-and-drop

Знак @ – добавление контекста (файлы, папки, открытые документы). Пример: @report.docx исправь оформление по ГОСТ.

Знак / – slash‑команды: /help, /newtask и др.

Нажав на значок +, можно перетаскивать файлы, изображения, PDF, таблицы прямо в чат.

Совет: Используйте режим Act только после того, как проверите план в режиме Plan. Это поможет избежать нежелательных изменений в проекте.

Настройка агентов: системные файлы AGENTS.md, QWEN.md, Project.md и другие

Агент – это ИИ-помощник, встроенный в вашу среду разработки (VS Code). Он может читать и создавать файлы, отвечать на вопросы, писать код, анализировать документы. Примеры агентов: Claude Code (от Anthropic), Qwen Code, GitHub Copilot, Cursor. В отличие от простого чата в браузере, агент имеет доступ к файловой системе вашего проекта и может выполнять действия (создать файл, изменить код, запустить команду).

По умолчанию агент не знает ваших предпочтений: на каком языке отвечать, какой стиль кода использовать, как организован проект, какие библиотеки запрещены. Каждый раз объяснять это вручную – утомительно.

Файлы конфигурации позволяют задать правила один раз, и агент будет им следовать в каждой сессии, экономя ваше время и обеспечивая единообразие. Обычно используют следующие расширения:

  • .txt – обычный текстовый файл без форматирования. Только буквы, цифры и знаки. Подходит для заметок, черновиков, простых записей.
  • .md – файл в формате Markdown. Позволяет делать заголовки, списки, жирный/курсивный текст, таблицы, ссылки и вставлять код. При этом остаётся читаемым и в обычном блокноте. Удобен для конспектов, отчётов, инструкций и документации.

Как писать хорошие инструкции?

Правило 1

Отдавайте предпочтение "что делать", а не "как не надо": вместо списка запретов лучше писать чёткие позитивные инструкции. Агенты лучше следуют прямым указаниям, а не пытаются обойти ограничения.

Правило 3

Что должно быть в файле:

  • общая информация: краткое описание проекта и его архитектуры;

  • критичные запреты, например, «никогда не удаляй файлы из папки /data»;
  • команды для сборки и тестов: как запустить проект, проверить код и убедиться, что изменения ничего не сломали.

Создание презентации в Visual Studio Code с помощью HTML

В Visual Studio Code студент может подготовить презентацию не только в виде текстового плана, но и в виде HTML-презентации, то есть набора слайдов, открываемых в браузере. Создание презентации в Visual Studio Code с помощью HTML аналогично разработке веб-страницы: каждый слайд оформляется как отдельный блок, структура и содержание задаются с помощью HTML, внешний вид настраивается через CSS (цвета, шрифты, анимации). Такой подход позволяет создавать гибкие, интерактивные презентации с полной настройкой дизайна и логики отображения, в отличие от классических инструментов вроде Microsoft PowerPoint.

Шаг 1

Создание файла для презентации. После открытия рабочей папки в Visual Studio Code необходимо создать новый файл, в котором будет размещён код будущей презентации. Для этого необходимо:

  • в левой панели Explorer нажать кнопку «Новый файл»;
  • ввести название файла, например: presentation.html;
  • нажать Enter.

Именно в этот файл в дальнейшем будет вставляться HTML-код презентации, сгенерированный с помощью нейросети или доработанный вручную.

Шаг 2

Подготовка содержания презентации. Перед генерацией HTML-кода рекомендуется сначала продумать содержание будущей презентации. На этом этапе желательно определить:

  • тему презентации;
  • предполагаемое количество слайдов;
  • структуру выступления;
  • ключевые тезисы;
  • основные выводы.

Это необходимо для того, чтобы нейросеть могла сгенерировать более логичную и качественную презентацию.

Шаг 3

Использование нейросети для создания структуры презентации. Если студенту сложно самостоятельно составить структуру, можно сначала обратиться к нейросети с запросом на создание плана слайдов.

Пример промта:

«Составь структуру учебной презентации на [количество слайдов] слайдов по теме [название темы] для студента вуза. Для каждого слайда укажи его название и краткое содержание. Структура должна быть логичной, академичной, понятной и подходить для устного выступления.»

После получения ответа студент может использовать предложенную структуру как основу будущей презентации.

Шаг 4

Подготовка краткого содержания слайдов. После того как структура определена, нейросеть можно использовать для подготовки краткого содержания каждого слайда.

Пример промта:

«Подготовь краткий текст для учебной презентации на тему [название темы]. Для каждого слайда сформулируй заголовок и [количество тезисов] кратких тезисов. Текст должен быть академичным, понятным, логичным и подходить для студенческого выступления.»
Шаг 5

Генерация полного HTML-кода презентации. После подготовки структуры и содержания можно перейти к созданию самой HTML-презентации. Для этого необходимо попросить нейросеть не просто составить текст, а сгенерировать полный HTML-код презентации.

Пример промта:

«Создай HTML-презентацию на тему [название темы] для студенческого выступления в вузе. Презентация должна содержать [количество слайдов] слайдов и быть выполнена в современном, аккуратном и визуально привлекательном стиле. Используй светлый фон, крупные заголовки, карточки, списки, удобочитаемый текст и логичное расположение элементов. Добавь кнопки переключения между слайдами "Назад" и "Вперёд", а также поддержку переключения стрелками клавиатуры. Подготовь полный HTML-код со встроенными CSS-стилями и JavaScript.»
Шаг 6

Сохранение сгенерированного кода. Попросите нейросеть самостоятельно создать файл в вашей папке и записать туда сгенерированный код. После этого HTML-презентация уже будет сохранена как рабочий файл проекта.

Шаг 7

Открытие презентации в браузере. После сохранения HTML-файла презентацию необходимо открыть в браузере. Для этого можно:

  • найти файл presentation.html в папке проекта;
  • дважды щёлкнуть по нему мышью;
  • либо открыть его через браузер вручную.

После этого презентация отобразится как полноценная веб-страница.

Как понять, что код вставлен правильно?

Если код вставлен корректно, внутри файла presentation.html должны присутствовать следующие основные элементы:

  • структура HTML-документа (<!DOCTYPE html>, <html>, <head>, <body>);
  • блоки оформления (<style>);
  • блоки с содержанием слайдов;
  • элементы навигации;
  • скрипт переключения слайдов (<script>).
Как сделать презентацию визуально красивой?

После получения первого варианта HTML-презентации рекомендуется улучшить её оформление. Часто нейросеть создаёт рабочую, но достаточно простую версию. Поэтому полезно дополнительно запросить улучшение дизайна.

Пример подробного промта:

«Улучшай оформление данной HTML-презентации. Сделай её более современной, красивой и удобной для учебного выступления. Используй крупные заголовки, мягкие тени, карточки, аккуратные отступы, современную типографику, приятную цветовую гамму и плавные переходы между слайдами. Сохрани структуру презентации, но сделай её визуально более профессиональной и привлекательной.»
Как сделать презентацию более академичной?

Если презентация предназначена для защиты реферата, проекта или учебного доклада, её оформление должно быть не только красивым, но и уместным для академической среды. Для этого можно использовать отдельный запрос.

Пример подробного промта:

«Переделай HTML-презентацию в более академичном стиле. Сделай дизайн аккуратным, строгим, современным и подходящим для выступления студента в вузе. Используй спокойные цвета, читабельные шрифты, логичное расположение текста, чистые блоки и минималистичное оформление. Не перегружай слайды лишними декоративными элементами.»
Как сократить или улучшить текст на слайдах?

После генерации презентации студент может заметить, что некоторые слайды перегружены текстом. В этом случае нейросеть можно использовать для сокращения и упрощения содержания.

Примеры полезных промтов:

  • «Сократи текст данной презентации так, чтобы каждый слайд содержал только ключевые мысли.»
  • «Сделай текст на слайдах более кратким и удобным для восприятия.»
  • «Преобразуй длинные абзацы в короткие тезисы для слайдов.»
  • «Сделай текст более понятным и логичным для устного выступления.»
Как вставить изображение в HTML-презентацию?

При создании HTML-презентации в Visual Studio Code нейросеть может не только сгенерировать структуру и оформление слайдов, но и вставить изображения в код презентации. Однако для этого необходимо правильно указать путь к файлу изображения, чтобы нейросеть смогла встроить его в HTML-код.

Шаг подготовки

Перед тем как просить нейросеть вставить изображение в презентацию, необходимо:

  • создать папку images (или другое название) внутри папки проекта;
  • поместить в неё нужные изображения;
  • убедиться, что файл имеет понятное имя;
  • желательно использовать латинские буквы и цифры в названии файла (например, ai.jpg, education_slide.png).

Чем проще название файла, тем легче его использовать в коде и в запросах к нейросети.

Примеры промтов для вставки изображения
  • «Добавь в HTML-презентацию изображение с путём [вставьте путь файла] на слайд [название слайда]. Размести изображение под текстом слайда, сделай его аккуратным, адаптивным, со скруглёнными углами и современным оформлением.»
  • «Вставь в HTML-код моей презентации изображение [вставьте путь файла] на слайд [название слайда]. Размести изображение под списком тезисов, сделай его шириной около 500 пикселей, добавь скруглённые углы, отступ сверху и мягкую тень. Сохрани общий современный стиль презентации.»
  • «Добавь в HTML-презентацию изображение [вставьте путь файла] на слайд [название слайда]. Размести текст слева, а изображение справа. Сделай слайд современным и аккуратным: используй карточки, отступы, скругления, удобочитаемый текст и адаптивное расположение элементов.»
  • «Добавь в HTML-презентацию два изображения: [вставьте путь файла] и [вставьте путь файла]. Первое изображение вставь на слайд [название слайда], второе – на слайд [название слайда]. Сделай оба изображения аккуратными, адаптивными, одинаково оформленными и визуально согласованными с общим стилем презентации.»
Рекомендация: После каждого изменения сохраняйте файл и проверяйте презентацию в браузере, чтобы убедиться, что все элементы отображаются корректно.

Создайте отдельную папку по учебной дисциплине.

Помощь нейросети в написании аннотаций

Аннотация - это краткая характеристика статьи, курсовой или исследовательской работы, которая раскрывает её тему, цель, основные результаты и выводы. Написание качественной аннотации часто вызывает трудности, но нейросеть может стать отличным помощником.

В Visual Studio Code с расширениями Qwen или GitHub Copilot Chat вы можете автоматически сгенерировать аннотацию на основе текста вашей работы. Достаточно скопировать ключевые разделы (введение, цели, выводы) и дать чёткий запрос.

Как составить эффективный запрос для генерации аннотации

Шаг 1

Соберите исходный материал - вставьте в чат нейросети следующие части вашей работы:

  • тему работы;
  • цель и задачи исследования;
  • краткое описание методов или хода работы;
  • основные выводы или полученные результаты.
Шаг 2

Используйте готовый шаблон промта - скопируйте и адаптируйте под свою тему.

«Напиши аннотацию для учебной работы по теме: [вставьте тему].

Цель работы: [опишите цель].
Методы / ход работы: [кратко опишите].
Полученные результаты: [основные выводы].

Требования к аннотации:
- объём: 100–200 слов;
- академический стиль;
- кратко отразить цель, ход и результаты;
- не использовать местоимения «я», «мы»;
- язык: русский.

Оформи аннотацию как готовый текст для курсовой работы.»
Шаг 3

Уточните и доработайте результат - нейросеть может выдать черновик, который лучше отредактировать. Попросите её сократить или расширить текст:

«Сократи аннотацию до 80 слов, сохрани главную мысль.»
- или -
«Расширь аннотацию, добавь информацию о практической значимости работы.»

🌐 Перевод научных статей с английского на русский

Нейросети (Qwen, ChatGPT, GitHub Copilot Chat) хорошо справляются с переводом научных текстов, но важно правильно составить промт. Ниже приведены готовые шаблоны для разных ситуаций.

Шаблон 1. Базовый перевод научной статьи

Для перевода аннотаций, рефератов, введений.

«Переведи следующий научный текст с английского на русский. Сохрани академический стиль, терминологию и смысл. Не добавляй от себя и не сокращай. Используй русские эквиваленты терминов из официальной научной литературы. Текст: [вставьте текст для перевода]»
Шаблон 2. Перевод с сохранением ссылок и цитирований

Для статей, где важны библиографические ссылки.

«Переведи научную статью с английского на русский. Не меняй формат ссылок ( [1], [2] , DOI, имена авторов). Сохрани цитирования и библиографию в исходном виде. Переведи только основной текст. Текст: [вставьте текст]»
Шаблон 3. Перевод с глоссарием терминов

Для узкоспециализированных текстов (медицина, физика, IT).

«Ты - переводчик научных текстов. Переведи следующий текст с английского на русский. Используй прилагаемый глоссарий для перевода ключевых терминов. Сохрани научный стиль и точность. Глоссарий: [термин] → [перевод] [термин] → [перевод] Текст: [вставьте текст]»
Шаблон 4. Быстрый перевод (черновик)

Когда нужно понять общий смысл, а не идеальный перевод.

«Сделай быстрый перевод этого научного текста с английского на русский. Не требуется идеальный литературный стиль, главное - передать смысл. Можно опустить второстепенные детали. Текст: [вставьте текст]»
Шаблон 5. Перевод + редактирование (адаптация под стиль)

Для адаптации перевода под конкретные требования (журнал, ВАК, учебное заведение).

«Переведи текст с английского на русский, а затем адаптируй под академический стиль российских научных журналов. Избегай кальки с английского, замени их на общепринятые русские обороты. Сохрани точность терминов. Текст: [вставьте текст]»
Шаблон 6. Перевод с английского на русский и обратная проверка

Для проверки качества перевода (нейросеть переводит туда-обратно).

«Сначала переведи следующий научный текст с английского на русский. Затем переведи полученный русский текст обратно на английский. Сравни исходный и обратный перевод. Если есть различия по смыслу - исправь русский перевод. Текст: [вставьте текст]»
Шаблон 7. Перевод экспериментальных данных и таблиц

Для статей с таблицами, формулами, цифрами.

«Переведи научную статью с английского на русский. Сохрани все цифры, единицы измерения, формулы и названия таблиц. Названия таблиц и подписи к рисункам также переведи. Формулы и числа не меняй. Текст: [вставьте текст]»
💡 Совет: Для лучшего качества перевода разбивайте длинные статьи на части по 2–3 абзаца. Указывайте область науки (физика, биология, IT и т.д.) - нейросеть будет точнее подбирать термины.

Возможные проблемы

Проблема 1. Установил расширение, но оно не появилось на панели, и пользователь не знает, как его открыть

Что делать:

  • - Перезапустите VS Code – часто этого достаточно.
  • - Проверьте левую панель – после перезапуска должна появиться новая иконка (логотип Qwen, ChatGPT и т.п.). Нажмите на неё.
  • - Если иконки нет, откройте чат через командную палитру:
    • - нажмите Ctrl+Shift+P;
    • - начните вводить название расширения, например Qwen: Open Chat;
    • - выберите команду и нажмите Enter.
  • - Если команды тоже нет – расширение не установилось правильно. Откройте расширения (Ctrl+Shift+X), найдите его, нажмите шестерёнку → Disable, затем снова Enable, и перезапустите VS Code.
Проблема 2. После установки нейросеть всё равно не отвечает, и студент не понимает, как проверить, работает ли она вообще

Что делать:

  • - Проверьте интернет – откройте любой сайт в браузере (например, google.com). Если сайты не открываются – проблема с интернетом.
  • - Перезапустите VS Code – закройте программу полностью, откройте снова, попробуйте написать простой запрос, например: «Привет, как дела?».
  • - Проверьте, выбрано ли правильное расширение – на левой панели нажмите на иконку нейросети. Если у вас установлено несколько расширений, отключите ненужные (шестерёнка → Disable).
  • - Перезагрузите окно VS Code: Ctrl+Shift+P → «Reload Window». Попробуйте снова.
  • - Если ошибка осталась – сделайте скриншот ошибки и покажите преподавателю.
Проблема 3. Студент не может переключиться между разными чатами (начал новую тему, а старая пропала)

Что делать:

  • - В панели расширения (там, где открыт чат) обычно есть список всех ваших диалогов. Ищите слева или сверху раздел «Chats», «History» или просто список с названиями.
  • - Чтобы открыть старый чат – нажмите на его название. Чтобы создать новый – нажмите кнопку «New Chat» (плюсик или «+»).
  • - Возможно, расширение не сохраняет историю. Некоторые расширения требуют входа в аккаунт для сохранения истории. Проверьте настройки расширения (иконка шестерёнки).

Важно: старые чаты не удаляются сами. Если вы не видите список, возможно, панель истории свёрнута – нажмите на иконку «History» или «Список чатов».

Проблема 4. Случайно закрыл панель с чатом и не знает, как её вернуть

Что делать:

  • - Самый быстрый способ: нажмите Ctrl+B (это показывает/скрывает боковую панель).
  • - Если боковая панель открыта, но чат не виден – посмотрите на иконки сверху. Нажмите на иконку вашего расширения.
  • - Если иконка пропала – значит, расширение отключилось. Откройте расширения (Ctrl+Shift+X), найдите ваше расширение и нажмите «Enable».
  • - Крайний случай: нажмите Ctrl+Shift+P, введите «Reload Window» и нажмите Enter. VS Code перезагрузится, и панели вернутся.
Проблема 5. В чате пропадает часть текста или ответ обрезается

Что делать:

  • - У некоторых расширений есть ограничение на длину ответа. Если ответ слишком длинный, он может обрезаться.
  • - Попросите нейросеть: «Выдавай ответ по частям. Сначала первую половину, потом я скажу "продолжи"» или «Разбей ответ на несколько сообщений».
  • - Если проблема повторяется постоянно – проверьте настройки расширения. Возможно, там можно увеличить лимит символов.
Проблема 6. Не может открыть существующий файл, чтобы скопировать из него текст для нейросети

Что делать:

  • - В VS Code файлы открываются так: Ctrl+O – открыть файл (выбрать в проводнике). Или перетащить файл мышкой из папки в окно VS Code.
  • - Если файл не открывается: проверьте, не занят ли файл другой программой (например, Word или Adobe Reader). Закройте файл в других программах, попробуйте снова.
  • - VS Code не умеет показывать PDF как текст. Нужно скопировать текст из другой программы (браузера, Adobe Reader) и вставить в чат. Также можно попросить GitHub Copilot Chat переконвертировать нужный файл в подходящий формат.
Проблема 7. Сохранил файл с ответом нейросети, но не может найти его потом

Что делать:

  • - Где VS Code сохраняет файлы по умолчанию: если вы не выбирали папку, VS Code мог сохранить файл в последнюю открытую папку или в домашнюю директорию пользователя. Нажмите Ctrl+O (открыть файл) и посмотрите, в какой папке вы находитесь.
  • - Как найти потерянный файл: в VS Code нажмите Ctrl+P (быстрый поиск файлов) и начните вводить название файла. В Windows откройте проводник, в строке поиска введите имя файла.
  • - Чтобы не терять в следующий раз: перед сохранением нажмите Ctrl+S – появится окно «Сохранить как», где вы сами выберете папку и имя файла. Называйте файлы понятно, например: «презентация_биология_1вариант.txt».
Проблема 8. Нейросеть перестала отвечать после того, как VS Code долго был открыт

Что делать:

  • - VS Code иногда «устаёт» – особенно если открыто много вкладок или расширений.
  • - Перезагрузите VS Code без закрытия вкладок: нажмите Ctrl+Shift+P, введите «Reload Window» и нажмите Enter. VS Code перезагрузится, чат откроется заново, история сохранится.
  • - Если не помогло – закройте VS Code полностью и откройте снова.
Проблема 9. При попытке вставить длинный текст в чат VS Code зависает

Что делать:

  • - Некоторые расширения не справляются с очень длинным текстом (более 10–20 тысяч символов).
  • - Разбейте текст на части (по 5–10 абзацев) и отправляйте частями, как описано в проблеме 5.
  • - Если VS Code завис: подождите 1–2 минуты – возможно, он обрабатывает текст. Если не отвечает – закройте VS Code через диспетчер задач (Ctrl+Shift+Esc → найти VS Code → «Снять задачу»). Откройте заново и попробуйте отправить текст меньшими частями.
Проблема 10. Установил VS Code, но при попытке открыть чат с нейросетью вылезает ошибка про Python

Что делать:

  • - Многие расширения для нейросетей требуют, чтобы был установлен Python.
  • - Как проверить: откройте терминал в VS Code (нижняя панель, иконка >_ или нажмите Ctrl+`). Напишите python --version и нажмите Enter. Если пишет «не является внутренней или внешней командой» – Python не установлен.
  • - Что делать: скачайте Python с официального сайта (https://www.python.org/), при установке обязательно поставьте галочку «Add Python to PATH». Перезагрузите VS Code после установки.

Важно: иногда будет достаточно загрузить внутреннее расширение Python.

Проблема 11. Установил Python, но VS Code всё равно не видит его

Что делать:

  • - Проверьте, что Python добавился в PATH: закройте VS Code полностью. Откройте командную строку Windows (Win+R → cmd → Enter). Напишите python --version – если показывает версию, всё хорошо.
  • - Если в командной строке работает, а в VS Code нет: перезагрузите компьютер (иногда нужно). В VS Code нажмите Ctrl+Shift+P, введите «Python: Select Interpreter» и выберите установленную версию Python.
  • - Если не помогло: переустановите Python, снова убедившись, что галочка «Add to PATH» стоит.
💡 Общая рекомендация: При возникновении любой проблемы в первую очередь пробуйте перезагрузить окно VS Code (Ctrl+Shift+P → «Reload Window»). Это решает большинство мелких сбоев без потери данных.
