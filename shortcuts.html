⌨️ Горячие клавиши

Сочетания клавиш, которые ускорят вашу работу в 2 раза

📌 Универсальные (Windows / VS Code / Браузер)

Ctrl + S
Сохранить
Сохраняет текущий файл. Привыкайте нажимать каждые 5 минут!
Ctrl + C
Копировать
Копирует выделенный текст или объект в буфер обмена.
Ctrl + V
Вставить
Вставляет скопированное из буфера обмена.
Ctrl + X
Вырезать
Вырезает выделенное (копирует и удаляет).
Ctrl + Z
Отменить
Отменяет последнее действие. Спасает постоянно!
Ctrl + Y / Ctrl + Shift + Z
Вернуть
Возвращает отменённое действие.
Ctrl + F
Поиск
Открывает окно поиска по тексту на странице.
Ctrl + Shift + F
Поиск по файлам
Ищет слово во всех файлах открытой папки (VS Code).
Ctrl + + / Ctrl + -
Масштаб
Увеличивает или уменьшает масштаб (везде).
Ctrl + B
Боковая панель
Показывает/скрывает боковую панель (VS Code).
🍎 Для пользователей Mac: Вместо клавиши Ctrl используйте ⌘ Cmd. Например, Ctrl+S → ⌘+S, Ctrl+C → ⌘+C, Ctrl+V → ⌘+V.
